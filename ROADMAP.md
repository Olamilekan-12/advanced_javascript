The roadmap:

Phase 1 — Advanced JS Core (the stuff most "JS devs" never actually learn)

Execution context, scope chain, hoisting internals
Prototypes & prototypal inheritance (the real mechanism behind class)
this binding edge cases, call/apply/bind
Closures (advanced patterns: memoization, currying, module pattern)
Event loop, microtask/macrotask queue, async internals
Generators, iterators, Symbol.iterator
Proxy & Reflect
Memory management, garbage collection, memory leaks

Phase 2 — OOP in JS

Prototypal OOP vs classical class syntax
Encapsulation (closures, #private fields, WeakMap technique)
Inheritance vs composition (why composition usually wins)
Polymorphism, mixins
Core design patterns (Factory, Singleton, Observer, Strategy, Decorator) implemented in vanilla JS

Phase 3 — Data Structures (built from scratch in JS, not just used)

Arrays/Strings (deep dive on complexity)
Linked Lists (singly/doubly)
Stacks & Queues
Hash Maps (how they actually work under the hood)
Trees (BST, traversals, balanced trees)
Heaps / Priority Queues
Graphs (adjacency list/matrix, BFS/DFS)
Tries

Phase 4 — Algorithms

Recursion & backtracking
Two pointers / sliding window
Sorting & searching (and why/when)
Dynamic programming (memoization → tabulation)
Greedy algorithms
Graph algorithms (Dijkstra, topological sort, union-find)

Phase 5 — LeetCode, pattern-mapped

Not random grinding — mapped to the ~15 core patterns (two pointers, sliding window, fast/slow pointers, merge intervals, DP, backtracking, etc.)
Easy → Medium → Hard, tagged by pattern, each solved cold first then reviewed for optimal approach

Each lesson: Learn (concept + why it matters) → Build (you write it) → Break (I throw edge cases/bugs at you) → Debug (you fix it).
